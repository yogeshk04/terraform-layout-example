# examples

Self-contained samples that demonstrate the reusable modules in
`../modules/`. Each example uses **local** state — they are not intended
for real environments. Copy patterns from here into `environments/*` when
you want them for real.

| Example       | Shows                                                                |
| ------------- | -------------------------------------------------------------------- |
| `vpc-and-s3/` | Standalone VPC (with NAT) + private S3 bucket, both from `modules/`. |
